# JasaWebPro - Solusi Digital Profesional

Website perusahaan jasa pembuatan website, aplikasi mobile, dan layanan digital marketing.

## 🚀 Fitur Utama

- **Hero Section** - Landing page dengan animasi modern
- **Services** - 6 layanan digital premium
- **Trust Signals** - Keunggulan dan statistik perusahaan
- **Contact Form** - Form kontak dengan pengiriman email otomatis
- **WhatsApp Integration** - Chat langsung ke WhatsApp dengan template pesan
- **Responsive Design** - Tampilan optimal di semua perangkat
- **Dark Mode Support** - Mendukung tema gelap dan terang
- **Email Notification** - Notifikasi email ke admin dan pengirim

## 🛠️ Teknologi

- Next.js 14
- TypeScript
- Tailwind CSS
- React Hook Form
- Nodemailer
- SweetAlert2
- Lucide React

## 📦 Instalasi

```bash
# Clone repository
git clone https://github.com/lavenderpoet607/jasawebpro.git
cd jasawebpro

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env.local

# Jalankan development server
npm run dev
